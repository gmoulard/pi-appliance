Prototype pour Raspberry Pi 5, 4, 3 B+ et Zero 2 W

Votre serveur, à la maison.

Une console en français pour installer et gérer vos services chez vous. Le projet avance : la première image système est construite, les essais sur un vrai Pi restent à faire.

Objectif du projet : moins de 15 minutes entre la carte SD et Nextcloud prêt à l’emploi. Cette version est encore expérimentale.

Le parcours visé

  1. 1

    Flashez

    Copiez l’image pi-appliance sur une carte SD.

  2. 2

    Branchez

    Le Pi démarre. Sans réseau, il crée un Wi-Fi « pi-appliance » : choisissez celui de la maison depuis votre téléphone.

  3. 3

    Choisissez

    Installez vos applications depuis la console. L’accès depuis internet fait partie des prochaines étapes.

Ce parcours décrit la cible du projet ; l’image construite n’a pas encore été validée sur un Raspberry Pi.

Télécharger l’image expérimentale

Une image a été construite avec succès par GitHub Actions.

Elle n’a pas encore été testée sur un vrai Raspberry Pi : c’est une version expérimentale, sans garantie. L’artefact temporaire est disponible jusqu’au 3 décembre 2026. La page indique aussi comment vérifier la somme SHA-256 et flasher l’image.
