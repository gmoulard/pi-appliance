# Contribuer à pi-appliance

Tout le monde peut participer : signaler un problème, proposer une idée, corriger un texte ou du code.

## Comment proposer une modification

1. Ouvrez une demande (« issue ») sur [GitHub](https://github.com/gmoulard/pi-appliance/issues) pour décrire le problème ou l'idée.
2. Copiez le dépôt (« fork »), faites vos modifications sur une branche, puis ouvrez une demande de fusion (« pull request ») vers le dépôt officiel.
3. Lisez d'abord [`CLAUDE.md`](CLAUDE.md) (règles du code, en-tête de licence, tests), la [spécification](docs/specification.md) et l'[avancement](docs/TODO.md).

La licence ([`LICENSE`](LICENSE), CC BY-NC-ND 4.0 avec des permissions supplémentaires) vous permet de publier une version modifiée **uniquement pour la proposer au dépôt officiel**. Elle ne vous permet pas de la diffuser pour un autre usage.

1. **Vos droits.** Vous gardez vos droits d'auteur sur votre contribution.

Cette licence permet d'utiliser, copier, modifier, diffuser et publier votre contribution, et de la placer sous toute licence, y compris une licence commerciale ou une autre licence à l'avenir.
3. **Brevets.** Si votre contribution touche un brevet qui vous appartient, vous accordez la même licence pour ce brevet, dans la mesure où votre contribution l'utilise.
4. **Vous en avez le droit.** Votre contribution est votre œuvre, ou vous avez le droit de la proposer à ces conditions. Si elle reprend un élément d'un tiers, vous l'indiquez avec sa licence dans la demande de fusion. Si vous contribuez pour votre employeur, vous avez son accord.
5. **Pas d'obligation.** L'auteur n'est pas obligé d'accepter votre contribution. Elle est fournie telle quelle, sans garantie.

Ouvrir une demande de fusion vaut acceptation de cet accord. Ajoutez la ligne suivante à vos commits avec `git commit -s` :

